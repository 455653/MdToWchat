# fixtures 回归样本

这里的 12 个文件是渲染管线的回归输入，`test/assert.html` 会逐个跑一遍。

## 为什么描述写在这里，不写在样本文件里

样本文件本身要被渲染。如果每个文件开头写一段「本文件用于测试 XX」的说明，
那段说明就会变成正文，出现在预览、统计和断言结果里——断言就会去检查一段
为了解释断言而写进去的文字。所以样本文件里只有它要测的内容，描述全部集中在本表。

## 清单

| 文件 | 覆盖点 | 故意做极端的地方 |
| --- | --- | --- |
| `01-basic.md` | 段落、加粗斜体删除线、行内代码、引用、分隔线、软换行 | 正文里塞了 `<div onclick="alert('xss')">`、`<script>alert(1)</script>` 等伪装 HTML，用来证明渲染走的是 `textContent` 而不是 `innerHTML` |
| `02-headings.md` | 一级到六级标题、标题里的行内标记、连续标题 | 从二级直接跳到五级；还写了一个「空标题」`##` 和三个连续标题，专门制造标题间距叠加的场景 |
| `03-lists.md` | 三层嵌套无序列表、有序列表里嵌无序、任务列表、列表项内多块 | 三层嵌套且每层文字都很长，折行后缩进是否还对得上；另有空列表项与只含空格的列表项 |
| `04-table-8col.md` | 八列表格、对齐标记、空单元格、单元格内转义竖线 | 8 列本身就超出手机可读宽度，另有一格写了近百字长文本，用单列就能撑破窄屏 |
| `05-code-long.md` | 代码块、超长单行、制表符、空代码块、不存在的语言标注 | 有一行长度超过 200 字符；有一个断不开的 100 字符英文单词；有一段没有任何空格与换行的连续中文 |
| `06-image-huge.md` | 图片引用、引用式图片、图片作为链接、行内 `<img>`、标题里放图片 | 图片 URL 带 5120x2880 的尺寸语义和超长查询串；行内 `<img>` 直接写死 600x400 宽高 |
| `07-quote-nested.md` | 三层（含第四层）嵌套引用、引用内放标题列表代码表格 | 嵌套到第四层，缩进按固定像素叠加时可用宽度会被吃掉一大半；引用里又塞了一次伪装 HTML |
| `08-admonitions.md` | 三种提示块写法（GitHub 警报、冒号容器、引用加粗） | 三种写法的视觉差异只能靠内联样式区分；另有连续三个提示块，用于观察上下间距 |
| `09-math.md` | 行内公式、独立公式块、`\(…\)` 与 `\[…\]` 写法 | 有一组多行 `aligned` 超长公式；还有不配对的美元素 `$100`、代码块里的 `$x^2$` 这两个误判陷阱 |
| `10-mermaid.md` | 流程图、时序图、类图、甘特图、饼图 | 有一个空图表和一个语法错误的图表，以及「未被渲染时必须是代码文本而不是空白」的要求 |
| `11-cjk-emoji.md` | 中英混排、超长英文单词、多码点 emoji、全角标点、CJK 混排、变音符号 | 有 4 码点的家庭 emoji 与带肤色修饰的组合 emoji（字符数统计最容易算错）；另有零宽空格 U+200B 和一段无空格的中英混合长串 |
| `12-link.md` | 行内链接、带 title 的链接、裸 URL、自动链接、mailto、引用式链接、图片链接 | 有超长裸 URL（约 170 字符）、中文域名 IDN、相对路径与页内锚点、以及嵌套链接这种非法写法 |

## 使用方式

打开 `test/assert.html`，用页面上的文件选择框一次多选本目录下的全部 12 个文件。
`file://` 下不允许脚本读本地路径，所以只能由人来选文件——这不是偷懒，是硬约束 3 的必然结果。
